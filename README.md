🎲 Python Dice Roller
A simple Python dice roller that allows the user to roll two six-sided dice repeatedly until they choose to exit.
🚀 Features
Roll two dice at the same time
Generate random numbers between 1 and 6
Continue rolling multiple times
Exit the game whenever you want
Handles invalid user input
🧠 Concepts Used
This project helped me practice the following Python concepts:
while loops
if, elif, and else statements
User input with input()
String methods such as .lower()
The random module
random.randint()
f-strings
break statements
